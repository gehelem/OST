Dieser Abschnitt dokumentiert die WebSocket-API von OST für Entwickler, die einen Client erstellen möchten — Web, Mobil, Desktop oder jede andere Plattform, die eine WebSocket-Verbindung öffnen kann.

Der Server lauscht auf **Port 9624** (einfaches WebSocket) oder über einen Reverse-Proxy mit WSS. Alle Nachrichten sind JSON-Textframes.
