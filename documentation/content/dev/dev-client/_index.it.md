Questa sezione documenta l'API WebSocket di OST per gli sviluppatori che desiderano creare un client — web, mobile, desktop o qualsiasi altra piattaforma capace di aprire una connessione WebSocket.

Il server è in ascolto sulla **porta 9624** (WebSocket semplice) oppure tramite un reverse proxy in WSS. Tutti i messaggi sono frame di testo JSON.
