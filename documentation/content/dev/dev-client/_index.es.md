Esta sección documenta la API WebSocket de OST para los desarrolladores que deseen crear un cliente — web, móvil, escritorio, o cualquier otra plataforma capaz de abrir una conexión WebSocket.

El servidor escucha en el **puerto 9624** (WebSocket simple) o mediante un reverse proxy en WSS. Todos los mensajes son tramas de texto JSON.
