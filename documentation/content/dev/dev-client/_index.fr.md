Cette section documente l'API WebSocket d'OST pour les développeurs souhaitant créer un client — web, mobile, bureau, ou toute autre plateforme capable d'ouvrir une connexion WebSocket.

Le serveur écoute sur le **port 9624** (WebSocket simple) ou via un reverse proxy en WSS. Tous les messages sont des trames texte JSON.
